# Задники первого мира — набор v1

29.09.2026 созданы десять отдельных PNG, по одному на каждый уровень «Забытых мостов». Метод — встроенная генерация image_gen. Все изображения уровней 02–10 используют уровень 01 как образец стиля. Набор создан по текстовому описанию; это новые ассеты на просмотр, а не оригинальный визуальный референс из старой беседы.

В проекте: `assets/backgrounds/world_01/v1/`. Каталог для просмотра: `index.html` внутри этой папки. Там же находятся `README.md` с правилами размещения, `manifest.json` с размерами и контрольными суммами и `PROMPTS.md` с полными запросами.

Уровни 01–02: горизонтальные 1672 × 941. Уровни 03–05, 07, 10: панорамы 2172 × 724. Уровни 06, 08, 09: вертикальные 1086 × 1448. Это реальные размеры файлов, без искусственного увеличения.

Изображения предназначены для дальнего/среднего фона. Игровая геометрия, кнопки, двери, ящики, персонажи и коллизии добавляются отдельно. Дальние арки, мосты и мельницы — декорации. Каждый файл является цельной композицией: отдельные слои неба, руин, воды и тумана пока не выделены. Фон можно прокручивать как одну плоскость параллакса. Циклическое повторение не применять: края не бесшовные.

Следующий шаг — выбрать фон для серого прототипа и проверить читаемость персонажей, масштаб, кадрирование и края при предельном отдалении общей камеры. Окончательное размещение зависит от геометрии уровня. Одобрение нового набора и результаты проверки фиксировать здесь; будущие изменения сохранять в `v2`.
