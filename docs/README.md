# «Держись!» — проектная база

**Версия:** 0.1 · **Дата фиксации:** 29.09.2026 · **Стадия:** дизайн первого мира; играбельный прототип ещё не подтверждён.

Кооперативный платформер-головоломка для **2–4 игроков** на Godot. Рабочее название — «Держись!». Персонажи бегают, прыгают, хватаются друг за друга и замирают, становясь платформами. Из этих действий возникают живые лестницы, цепи, маятники, противовесы и катапульты.

> **Неизменяемое правило:** каждый уровень и каждый его участок сначала проектируется и проверяется как полностью проходимый **двумя** игроками. Только затем проверяются три и четыре игрока. Ни одна задача не требует третьего или четвёртого тела.

## Статус решений

- **Утверждено:** общее направление игры и финальный визуальный ориентир первого мира «Забытые мосты»; приоритет прохождения вдвоём; общий экран; 2D-геймплей с объёмным 2.5D видом; ядро «сцепка + платформа»; десять концептов уровней; производственный путь Blender → ортографический 2D-рендер → Godot.
- **Проектное уточнение этого пакета:** конкретные маршруты возврата второго игрока, защёлки механизмов и точки чекпоинтов в уровнях. Они нужны, чтобы двухместное решение было описано до реализации, но должны пройти проверку в сером прототипе.
- **Не зафиксировано численно:** скорость, высота прыжка, масса, сила хвата, длительность хвата, максимальный зум и конкретные размеры модулей. Эти значения не следует выдавать за уже согласованные.

## Как обновлять

Менять правило можно только явным новым решением пользователя. Измеренные величины и результаты плейтестов заносить в `06_параметры_и_решения.md`. Для новых уровней копировать `ШАБЛОН_УРОВНЯ.md`; сперва заполнять путь для двух игроков и условия возврата обоих к финишу. Новые изображения класть в `референсы/` с указанием источника и статуса утверждения.
