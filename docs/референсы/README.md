# Изображения референсов

**Состояние на 29.09.2026:** исходные утверждённые изображения из беседы «Создание кооперативной игры» не были доступны для извлечения. Доступный просмотр беседы содержал текст и пустой список вложений; в текущем запросе изображения также не приложены. Поэтому здесь нет вымышленных или заново созданных картинок под видом утверждённого оригинала.

Окончательный визуальный референс относится к игре и первому миру **«Забытые мосты»**: тёплые заросшие руины, дерево, камень, вода, солнечная долина, объёмный 2.5D вид и простые яркие персонажи. Текстовая фиксация находится в `../03_визуал_и_производство.md`.

Когда оригиналы появятся, сохранить сюда именно их, без перерисовки и подмены, например:

```text
базовый_референс_забытые_мосты.<формат>
уровень_01.<формат>
...
уровень_10.<формат>
```

Для каждого файла записать в этом README: название, источник/дату получения, статус утверждения и связь с уровнем. Если конкретных отдельных картинок для десяти уровней не существует, не создавать запись о якобы утверждённых изображениях.
