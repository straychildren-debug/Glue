### Что берём из `reference.png`

- **Стиль:** яркий мультяшный платформер; насыщенное синее небо, тёмный замшелый камень, дерево, верёвочные мосты, много водопадов; руины близко к игровому плану.
- **Персонажи:** простые округлые фигуры-«бобы» с обводкой, короткими руками и ногами, чёрными овальными глазами, без рта; красный, синий, жёлтый, зелёный. Хват — рука в руку.
- **Уровни:** названия и описания совпадают с `../02_забытые_мосты_уровни.md`; полоски-схемы под карточками — ориентир для серых уровней этапа 4.
- **Не берём:** надпись «локально или онлайн» — игра только локальная (решение 29.09.2026, см. `../06_параметры_и_решения.md`).

Задники `assets/backgrounds/world_01/v1/` по стилю от этого референса отличаются (пастельные дальние пейзажи). Для визуального прототипа (этап 5) нужен набор v2 по `reference.png`; v1 сохраняется.

## Как добавлять

Новые изображения сохранять сюда без перерисовки и подмены. Для каждого файла записать в таблицу: название, источник/дату получения, статус утверждения и связь с уровнем.
