# Параметры, формулы и решения

Этот файл отделяет **зафиксированные ориентиры беседы** от формул, которые ещё предстоит настроить. Незаполненное значение означает, что численного решения не было.

## Числа, присутствующие в исходной беседе

| Параметр | Значение и статус |
|---|---|
| Состав команды | 2, 3 или 4 игрока; твёрдое правило |
| Количество уровней в мире | **20** с нарастающей сложностью — решение пользователя 01.10.2026 (раньше было 10 концептов) |
| Общий ранний ориентир длины уровня | 1–3 минуты; ориентир, не проверенный норматив |
| Уровень 01 | около 20–30 секунд в раннем описании; ориентир |
| Уровень 01 по протяжённости | примерно 1–1,5 экрана; ориентир из производственного плана |
| Уровень 10 по протяжённости | условно 5–8 экранов с чекпоинтами; ориентир, не предел |
| Момент расширения уровней | примерно с 4–5 уровня допустимы маршруты на несколько экранов |
| Респавн | примерно через 1 секунду в концепте |
| Цена ошибки | ранний ориентир — 5–15 секунд, а не полный длинный рестарт |
| Размер мира | ранняя общая оценка 8–12 уровней; затем 10-уровневый план; 01.10.2026 утверждено 20 уровней в каждом мире |
| Библиотека первого мира | примерно 15 **типов** модулей |
| Первый комплект анимаций | примерно 10–12 анимаций/состояний; список включает отдельные направления наклона |
| Камера | есть максимальное отдаление, но численный предел не задан |
| Ослабление хвата | предусмотрено как правило, но длительность и скорость не заданы |

## Правила, выраженные как условия

- `N ∈ {2, 3, 4}` — число активных игроков.
- `solvable(level, N=2) = true` **для всего уровня и каждого его участка** — главный критерий. Затем требуется `solvable(level, 3) = true` и `solvable(level, 4) = true`.
- `geometry(level, 2) = geometry(level, 3) = geometry(level, 4)` — предпочтительное позднее решение. Меняться могут `mechanism_parameters(N)`: порог веса, число активных плит, сила пружины и аналогичные величины.
- `goal_reached = all(active_players_at_finish)` — уточнение для проектирования: переход одного игрока не завершает уровень.
- Одинаковы действия и размеры хитбоксов всех цветовых вариантов персонажа.

## Расчётные зависимости для прототипа — ещё не согласованные значения

Эти записи переводят словесные правила в проверяемые места настройки. Они **не являются ранее утверждёнными физическими коэффициентами**.

| Подсистема | Зависимость для настройки | Что измерить в прототипе |
|---|---|---|
| Нажимная плита/подъёмник | `нагрузка = сумма масс касающихся игроков и ящиков`; срабатывание при `нагрузка ≥ порог(N)` | Достижим ли порог парой и доступным в уровне ящиком |
| Противовес | `разность нагрузки = нагрузка слева − нагрузка справа`; знак задаёт направление хода | Может ли пара перевести механизм и затем воссоединиться |
| Ослабление хвата | `запас хвата(t) = max(0, начальный запас − расход(нагрузка, движение) × t)` | Хватает ли запаса паре на каждый отрезок уровня 09 |
| Общая камера | рамка `B = bounding_box(все активные игроки) + поля`; масштаб ограничен `max_zoom_out` | Все ли видны на длинном уровне и не становятся слишком маленькими |
| Прыжок/дальность | расстояния уступов задаются относительно **измеренного** обычного прыжка пары и комбинаций с платформой/сцепкой | Проходится ли альтернативный маршрут для двух игроков без точного пиксельного исполнения |

Численные массы, гравитация, скорость, высота и длина прыжка, тяга, импульс катапульты, дальность хвата, длительность хвата, углы наклона, размеры тайла, экранное разрешение, пороги веса, параметры камеры и время чекпоинта **не были зафиксированы**. Их следует измерить и занести сюда после серого прототипа с датой и тестовой сценой.

## История уточнений

1. В раннем обсуждении упоминались изменяемые под 2/3/4 игрока число секций моста, геометрия и дополнительные предметы. Это действующее решение.
2. Сначала главным направлением была «Сцепка», затем пользователь выбрал симбиоз сцепки и превращения в платформу. Обе механики составляют одно ядро; вес — естественное физическое свойство, не отдельная способность.
3. Первый визуальный ориентир назывался нефинальным; затем пользователь одобрил последний вариант как **окончательный базовый референс** игры и «Забытых мостов». Его исходное изображение надо приложить, когда оно станет доступно.
4. Ранние короткие комнаты не ограничивают всю игру одним экраном. Последнее решение допускает горизонтальные и вертикальные маршруты на несколько экранов, одну камеру и чекпоинты.
5. **29.09.2026:** на концепт-листе `референсы/reference.png` написано «2–4 игрока (локально или онлайн)». Пользователь решил: **только локально, один экран, в основном геймпады**. Онлайн не делается; надпись на концепт-листе считать устаревшей. «Один экран» означает одно устройство вывода без разделения экрана; уровни по-прежнему могут быть длиннее одного кадра камеры.
