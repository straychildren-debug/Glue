# Вступление: мультик целиком кодом

**Дата:** 09.10.2026.

**Решение пользователя:** вступление «Истории» рисуется и анимируется кодом, без картинок генератора. Повод — мультфильм Anthropic про муравья.

**Откуда пришли:**
- Перекладка из картинок генератора ([18](18_мультик_задание.md)): персонажи «висели в воздухе».
- Комикс из панелей ([19](19_комикс_задание.md)): статичен.

**Что из них осталось:** отрисованные панели комикса служат раскадровкой, сценарий и реплики взяты из задания 19. Проба «налёт и похищение» понравилась: «Всё потрясающе». Замечание к ней — воротник короля выглядел как лишние глаза — исправлено.

## Где что лежит

Проект HyperFrames — `video/cartoon/`.

| Файл | Что |
|---|---|
| `index.html` | корень: SVG-сцена, звук, подключение скриптов, регистрация таймлайна |
| `lib/core.js` | числа, ключи анимации `K`, сплайны, общие градиенты, сцена с камерой и параллаксом |
| `lib/cast.js` | куклы: бобы — герои, горожане, король, старый боб; призраки; корона; пузыри, звуковые надписи, плашки рассказчика |
| `lib/places.js` | палитры времени суток; небо, облака, солнце, луна; парящие острова и мосты; замок; площадь с помостом; луг |
| `scenes/01_kingdom.js` … `09_bridge.js` | сцены по порядку |
| `main.js` | склейка сцен и время |
| `audio/make_score.py` | синтез музыки и звуков под тайминг сцен → `audio/score.wav` |

Каждый кадр — функция времени `render(t)`. Время ведёт один твин GSAP через функцию-сеттер, поэтому перемотка и рендер детерминированы.

## Как собрать

```bash
cd video/cartoon
python audio/make_score.py
npx --yes hyperframes@0.8.119 check
npx --yes hyperframes@0.8.119 render --workers 4 --output cartoon_full.mp4
```

**Правила при изменениях:**
- Если поменялась длина сцены, надо поправить `data-duration` в `index.html` (`main.js` предупредит о расхождении) и тайминг звуков в `audio/make_score.py`.
- После утверждения: перекодировать в `assets/video/intro.ogv` (ffmpeg, `-c:v libtheora -q:v 8 -c:a libvorbis`). Его играет `src/menu/cutscene.gd`.
