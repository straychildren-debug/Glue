## Как использовать

Папка в игре: `assets/backgrounds/world_01/v1/`. Поместить выбранный PNG позади игровой геометрии и персонажей как отдельную фоновую плоскость. Он не содержит коллизий и не задаёт расположение игровых платформ. На вертикальных уровнях фон движется по высоте, на горизонтальных — по ширине. У уровня 10 панорама может медленно прокручиваться за длинным маршрутом: число экранов игрового мира не равно числу экранов фона.

Каждый PNG — **цельная композиция**. Небо, горы, руины и вода внутри него не разделены по слоям. Его можно использовать как одну плоскость параллакса; для независимого движения неба, тумана и руин нужны отдельные дополнительные ассеты. Изображения не бесшовные: не включать циклическое повторение, которое склеит края.

Сохранять пропорции при масштабировании. Для видимого окна размером `Vw × Vh` и изображения `W × H` минимальный масштаб без пустых краёв: `s = max(Vw/W, Vh/H)`. Доступный запас прокрутки: `max(0, sW−Vw)` по X и `max(0, sH−Vh)` по Y. Эти формулы — подсказка по размещению новых ассетов, не ранее утверждённые параметры игры. Проверять кадрирование на максимальном отдалении общей камеры.

Предметы управления, ящики, дверь, персонажи, трава переднего плана и анимация водопада должны добавляться отдельно. Нарисованные дальние мосты, арки и мельницы — только декорации. Окончательную читаемость нужно проверить после появления игровой геометрии и персонажей.
